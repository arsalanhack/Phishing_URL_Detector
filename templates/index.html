About the Project

A semester project in applied machine learning

PhishGuard AI is a semester project for an Artificial Intelligence course. It classifies URLs as phishing or legitimate using a supervised machine learning model.

The classifier is trained with XGBoost on lexical and structural URL features. The backend is built with Flask, which handles feature extraction and serves predictions to this interface.
